# Networking Models

Networking Models are **conceptual frameworks** that define **how data is communicated, processed, and transferred** across a computer network.  
These models divide networking tasks into **layers**, making network design, implementation, troubleshooting, and learning easier.

> Networking models focus on **how communication happens**, not on physical devices or cables.

---

## Why Networking Models Are Needed

- To **standardize communication** between different vendors and systems  
- To **simplify complex networking processes**  
- To allow **independent development of protocols**  
- To make **learning and troubleshooting structured**

---

## Core Networking Models

At the **fundamental (core) level**, there are **only two networking models**:

1. **OSI Reference Model**
2. **TCP/IP Model**

All modern networking concepts are **based on these two models**.

---

## 1. OSI Reference Model

### Introduction
The **OSI (Open Systems Interconnection) Model** is a **theoretical reference model** developed by ISO to standardize network communication.

It divides networking into **7 logical layers**, where **each layer has a specific responsibility**.

> OSI model is mainly used for **learning, teaching, and understanding networking concepts**.

---

### OSI Model Layers (Top to Bottom)

1. **Application Layer**  
   - Provides network services to end users  
   - Examples: HTTP, FTP, SMTP, DNS  

2. **Presentation Layer**  
   - Data formatting, encryption, compression  
   - Ensures data is readable by receiver  

3. **Session Layer**  
   - Manages sessions between devices  
   - Controls session establishment, maintenance, termination  

4. **Transport Layer**  
   - End-to-end communication  
   - Reliability, flow control, error control  
   - Examples: TCP, UDP  

5. **Network Layer**  
   - Logical addressing and routing  
   - Path selection between networks  
   - Example: IP  

6. **Data Link Layer**  
   - Frame creation, MAC addressing  
   - Error detection  
   - Example: Ethernet  

7. **Physical Layer**  
   - Actual transmission of bits  
   - Cables, signals, voltages, connectors  

---

### Key Characteristics of OSI Model

- 7 layers  
- Strict separation of responsibilities  
- Conceptual / reference model  
- Not directly implemented in real networks  

---

## 2. TCP/IP Model

### Introduction
The **TCP/IP Model** is a **practical and implementation-based model** used in real-world networks, including the Internet.

It was developed by DARPA and is the **foundation of modern networking**.

---

### TCP/IP Model Layers

1. **Application Layer**  
   - Combines OSI Application, Presentation, and Session layers  
   - Examples: HTTP, FTP, SMTP, DNS  

2. **Transport Layer**  
   - End-to-end communication  
   - Examples: TCP, UDP  

3. **Internet Layer**  
   - Logical addressing and routing  
   - Example: IP  

4. **Network Access Layer**  
   - Combines OSI Data Link and Physical layers  
   - Examples: Ethernet, Wi-Fi  

---

### Key Characteristics of TCP/IP Model

- 4 layers  
- Practical and real-world implementation  
- Used by the Internet  
- Flexible and protocol-oriented  

---

## OSI Model vs TCP/IP Model

| Feature | OSI Model | TCP/IP Model |
|------|---------|-----------|
| Purpose | Conceptual / Teaching | Practical / Implementation |
| Number of Layers | 7 | 4 |
| Developed By | ISO | DARPA |
| Usage | Learning & reference | Real-world networking |
| Layer Separation | Strict | Flexible |

---

## Layered Communication Concept

In networking models:
- Each layer **provides services** to the layer above  
- Each layer **uses services** of the layer below  
- Same layers on sender and receiver communicate **logically (peer-to-peer)**

---

## Encapsulation and Decapsulation

### Encapsulation
- Process of **adding headers (and trailers)** to data as it moves **down the layers**  
- Each layer adds its own control information  

### Decapsulation
- Reverse process at receiver side  
- Headers are removed layer by layer  

---

## Services, Interfaces, and Protocols

- **Service:** What a layer offers to the upper layer  
- **Interface:** How layers interact internally  
- **Protocol:** Rules used by same layers on different devices  

---

## Key Takeaway

- Networking Models explain **how data communication works**
- **OSI and TCP/IP are the only core networking models**
- OSI = learning and understanding  
- TCP/IP = real-world implementation  

> All modern networks, protocols, and architectures are based on these models.

---

## Summary

- Networking Models = conceptual communication frameworks  
- Core models = OSI & TCP/IP  
- Layered design simplifies networking  
- Foundation for protocols, architectures, and network design
