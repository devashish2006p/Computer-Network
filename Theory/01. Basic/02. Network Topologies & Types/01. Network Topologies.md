# Network Topologies

## Definition

A **network topology** defines the **layout or arrangement of devices (nodes) and connections (links) in a network**.  
It determines **how devices communicate, how data flows, and the performance, reliability, and scalability of the network**.

---

## Perspectives of Network Topology

Network topologies can be analyzed from **two main perspectives**:

1. **Physical Perspective** – Actual layout of devices and cables.  
2. **Logical (Virtual) Perspective** – The data flow or communication pattern between devices.

---

# 1. Physical Topology

**Definition:**  
Physical topology refers to the **actual physical arrangement of network devices and cables**.  
It shows **how devices are physically connected**.

**Total Types:** 6

### Physical Topology Types

#### 1. Bus Topology
- **Structure:** All devices connected to a single central cable (bus).  
- **Characteristics:**  
  - Data travels in both directions.  
  - Simple and cost-effective.  
- **Advantages:** Easy to implement, low cost.  
- **Disadvantages:** Single cable failure disrupts network, performance decreases with more devices.

#### 2. Star Topology
- **Structure:** All devices connected to a central hub or switch.  
- **Characteristics:** Hub acts as a repeater for communication.  
- **Advantages:** Easy to manage, failure of one device does not affect network.  
- **Disadvantages:** Central hub failure stops entire network, requires more cables.

#### 3. Ring Topology
- **Structure:** Devices connected in a closed loop.  
- **Characteristics:** Data travels unidirectional or bidirectional around the ring.  
- **Advantages:** Equal access for all devices, less chance of collision.  
- **Disadvantages:** Single node failure can disrupt network, difficult to add/remove devices.

#### 4. Mesh Topology
- **Structure:** Every device connected to every other device.  
- **Characteristics:** Multiple paths for data; routing selects optimal path.  
- **Advantages:** Highly reliable, fault-tolerant.  
- **Disadvantages:** Expensive, complex setup.

#### 5. Tree Topology
- **Structure:** Combination of star and bus topologies; hierarchical structure.  
- **Characteristics:** Groups of star networks connected to a main bus.  
- **Advantages:** Scalable, isolates segments.  
- **Disadvantages:** Root node failure affects entire segment, requires more cable.

#### 6. Hybrid Topology
- **Structure:** Combination of two or more topologies.  
- **Characteristics:** Flexible design, incorporates advantages of multiple topologies.  
- **Advantages:** Scalable, adaptable.  
- **Disadvantages:** Complex, expensive.

---

# 2. Logical (Virtual) Topology

**Definition:**  
Logical or virtual topology defines **how data flows in a network**, regardless of physical connections.  

**Total Types:** 2

### Logical Topology Types

#### 1. Bus Logical Topology
- **Concept:** Data flows in a **single shared path** connecting all devices, like a bus.  
- **Characteristics:**  
  - All nodes see transmitted data.  
  - Only the intended recipient processes it.  
- **Example:** Ethernet LAN behaves logically as a bus, even if physically star.

#### 2. Ring Logical Topology
- **Concept:** Data flows in a **circular path** through all devices.  
- **Characteristics:**  
  - Token or control mechanism manages access.  
  - Logical flow can differ from physical layout.  
- **Example:** Token Ring network flows data in a logical loop.

---

## Key Points

- **Physical topology** shows the **real hardware layout**.  
- **Logical topology** shows **data flow patterns**, may differ from physical layout.  
- Total **physical types = 6**, total **logical types = 2**.  
- Every network design considers **both perspectives** for reliability, cost, and performance.
