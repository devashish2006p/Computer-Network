# Network Types

A **network type** defines the **size, range, and purpose** of a computer network.  
Networks can be classified based on **geographical area, ownership, or functionality**.  

---

## 1️⃣ PAN (Personal Area Network)
- **Definition:** A network for **personal devices**, usually within a **range of a few meters**.  
- **Range:** 1–10 meters  
- **Features:**  
  - Connects devices like smartphones, laptops, tablets, wearable devices  
  - Often uses **Bluetooth, Infrared, or USB connections**  
- **Advantages:**  
  - Easy to set up  
  - Low cost  
  - Convenient for personal use  
- **Disadvantages:**  
  - Very limited range  
  - Low security if wireless  
- **Use Cases:**  
  - Connecting phone to headphones  
  - Laptop to smartphone tethering  

---

## 2️⃣ LAN (Local Area Network)
- **Definition:** Network that connects devices in a **small geographical area** like a building or office.  
- **Range:** Up to 1 km  
- **Features:**  
  - High-speed connections  
  - Typically uses Ethernet or Wi-Fi  
  - Managed by **centralized devices like switches**  
- **Advantages:**  
  - High data transfer speed  
  - Easy sharing of resources (files, printers)  
  - Low error rate  
- **Disadvantages:**  
  - Limited to small area  
  - Requires setup and maintenance  
- **Use Cases:**  
  - Office networks  
  - School or university campus networks  

---

## 3️⃣ MAN (Metropolitan Area Network)
- **Definition:** Network that spans a **city or metropolitan area**.  
- **Range:** 5–50 km  
- **Features:**  
  - Connects multiple LANs  
  - Uses **fiber optics or high-speed links**  
- **Advantages:**  
  - Covers larger area than LAN  
  - High-speed network for organizations or city services  
- **Disadvantages:**  
  - Expensive to set up  
  - Complex maintenance  
- **Use Cases:**  
  - City-wide internet service  
  - Connecting offices across a city  

---

## 4️⃣ WAN (Wide Area Network)
- **Definition:** Network that covers a **large geographical area**, even countries or continents.  
- **Range:** Thousands of kilometers  
- **Features:**  
  - Connects multiple LANs and MANs  
  - Uses **public or private communication links** (Internet, satellite)  
- **Advantages:**  
  - Connects devices globally  
  - Enables remote communication and business operations  
- **Disadvantages:**  
  - Expensive  
  - Slower than LAN due to distance  
- **Use Cases:**  
  - The Internet  
  - Multinational company networks  

---

## 5️⃣ WLAN (Wireless LAN)
- **Definition:** LAN that uses **wireless technology** like Wi-Fi instead of cables.  
- **Range:** 30–100 meters indoors, more outdoors with access points  
- **Features:**  
  - Supports mobile devices  
  - Uses wireless standards like IEEE 802.11  
- **Advantages:**  
  - No cables, flexible setup  
  - Supports mobility  
- **Disadvantages:**  
  - Security risks  
  - Interference and lower speed than wired LAN  
- **Use Cases:**  
  - Home Wi-Fi  
  - Office Wi-Fi networks  

---

## 6️⃣ CAN (Campus Area Network)
- **Definition:** Network covering a **university, corporate campus, or school**.  
- **Range:** Multiple buildings within campus  
- **Features:**  
  - Connects multiple LANs  
  - High-speed backbone connections  
- **Advantages:**  
  - Efficient resource sharing across campus  
  - Centralized management  
- **Disadvantages:**  
  - Setup cost higher than LAN  
  - Requires network management  
- **Use Cases:**  
  - University campus network  
  - Corporate office complexes  

---

## 7️⃣ SAN (Storage Area Network)
- **Definition:** Specialized network for **connecting storage devices** to servers.  
- **Range:** Local or campus area  
- **Features:**  
  - High-speed data transfer for storage  
  - Dedicated network separate from regular LAN  
- **Advantages:**  
  - Fast and reliable data storage access  
  - Reduces load on main network  
- **Disadvantages:**  
  - Expensive setup  
  - Requires specialized management  
- **Use Cases:**  
  - Data centers  
  - Cloud storage infrastructure  

---

## 8️⃣ VPN (Virtual Private Network)
- **Definition:** Logical network over the **public internet** that behaves like a private network.  
- **Features:**  
  - Encrypts data  
  - Provides remote access to network resources  
- **Advantages:**  
  - Secure communication over public networks  
  - Enables remote work  
- **Disadvantages:**  
  - Requires configuration  
  - Performance depends on internet speed  
- **Use Cases:**  
  - Remote office access  
  - Secure connections for employees
